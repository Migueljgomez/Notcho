# Brain dump

A messy list that needs sorting into a plan.

Work in this order: sort, ask, then fit (SKILL.md step 4).

Put each into one of: **now** (this week), **later** (a set date or someday), **drop** (no longer worth doing), **idea** (not a task yet). An item counts as covered by an open task only when that task would finish it; otherwise it is a new task.
- **Ask:** anything that could go either way, in one short list, before the draft.
- **Horizon:** the next 5 working days for the "now" group. "Later" items go to their date or `someday`, with an estimate.
- **Tasks:** 15 to 90 minutes each; round anything quicker up to 15. Put each task in the project it belongs to; ask before creating a new project. "Drop" and "idea" items stay off the task list.
- **Blocks:** block the "now" tasks on the next 2 working days only.
- **Plan page:** in the handoff, add "Later:" (sent to someday by choice, separate from "Did not fit"), "Dropped:" and "Ideas:", so nothing from the dump is lost.
