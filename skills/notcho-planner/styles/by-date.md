# By a date

Done by tomorrow, or by a set deadline within about a week.

- **Horizon:** from today (or tomorrow, if today's hours are nearly gone) through the deadline. Ask for the date if it isn't given.
- **Tasks:** 30 to 90 minutes each. Set `due` to the deadline on every task.
- **Fit:** work backward from the deadline. Keep the last working day light, about half full, for review and fixes. If the total does not fit, say so before the draft and offer what to cut or a later date.
- **Blocks:** block every task in the horizon.
- **Plan page:** in the handoff, add "Deadline:" with the date and the one thing that must be done first.
