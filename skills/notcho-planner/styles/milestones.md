# Milestones

A bigger project in phases, weeks or months long.

- **Horizon:** the current phase, in detail. Later phases stay on the plan page only.
- **Phases:** split the project into 3 to 6 milestones, each with a clear "done when" and a target date. Ask for the overall date if there is none.
- **Tasks:** add tasks only for the current milestone, 30 to 90 minutes each, placed over its next 1 to 2 weeks. Set `due` to the milestone's date.
- **Blocks:** block the next 3 working days.
- **Plan page:** add a `## Milestones` section listing each milestone, its target date and its "done when", with the current one marked "(now)". Write it on the first run; on later runs, append an updated list only when milestones change. Under "Next", name the next milestone to plan.
