# Sprint

A 1 to 2 week push with one clear outcome.

- **Horizon:** the sprint's working days. Ask for the length (1 or 2 weeks) and the outcome if they aren't given.
- **Tasks:** 30 to 90 minutes each. Spread them over the days, with about one day's worth left unplanned near the end as buffer.
- **Goal:** add the outcome with `add_goal` if this week has fewer than 3 goals (check `list_goals`), and link the sprint's tasks to it with `update_task` `goal`.
- **Blocks:** block only the next 3 working days. Later days get tasks without blocks, since calendars change. The next run blocks the next 3.
- **Plan page:** in the handoff, add "Sprint:" with start and end dates and the outcome, and "Review on:" with the last day.
